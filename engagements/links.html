Explain the difference between an absolute link and a relative link. Why would you use relative links?
An absolute link uses a full web address as a link to enter another webpage whereas a relative link only uses the path from the current file to the other file, like engagements/structural.html.. You would use relative links to move one web domain to another without chaging anything.

List the 3 rules with relative links.

  1. If the file is in the same folder, use the file name.
  2. If the file is in a subfolder, type the folder name, slash, then the file name, for example: engagements/structural.html
  3. If the file is in a parent folder, use ../ to go up one level, for example: ../parent_file.html
