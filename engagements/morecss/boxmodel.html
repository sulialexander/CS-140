Questions

  1. What is the difference between block tags and inline tags?

    A block tag starts on a new line and stretches across the full width of the page. Inline tags, on the other hand, stay within a line of text and are only as wide as their content.

  2. What is the margin, border, and padding?

    Content is what's inside the box, like an image or text. Padding is the space inside the box between the content and the border. The border is the line around the box, essentially the frame. The margin is the space outside the border that separates the box from other elements on the page.

  3. What are units of measurement you can use in CSS?

    A fixed unit such as px keeps content the same size no matter what. Relative units change size based on something else: % is based on the parent element, vw is based on the width of the browser window, and rem is based on the page's base font size. For example, an image set to 300px stays the same size when I resize the window, but an image set to 50% gets smaller when the window gets narrower.

  4. When would you use a figure tag?

    A figure tag is used when you want an image to be separate from the text. Since an img tag is inline, wrapping it in a figure gives it its own block so it stands out. A figcaption tag can be added inside the figure to connect a caption to the image.
