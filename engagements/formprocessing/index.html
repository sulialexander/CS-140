Questions

What is JavaScript? How did it get its name?

JavaScript is a programming language that makes websites interactive. HTML is the structure and CSS is the look, but JavaScript is what lets the page actually do stuff, like check a form, show alerts, or change things on the page when you click something. It was first called Mocha, then LiveScript, and then they changed it to JavaScript because Java was popular at the time.

What are the two ways you can run JavaScript?

The first way is in the browser. You can put it inside a script tag in your HTML like I did here, link to a separate .js file, or just type it straight into the browser console. The second way is outside the browser using Node.js.

What is jQuery? Is it still popular today?

jQuery is a JavaScript library that made it way easier to do things like grab elements on the page, handle clicks, and add animations, and back then it also helped your code work the same across different browsers. It's not as popular for new projects anymore, because plain JavaScript can now do most of what jQuery used to do, and a lot of people use React instead. But it's still used on a ton of websites.

What is the most popular front-end js library today?

React, made by Facebook and it lets you build websites out of reusable pieces called components. In the 2025 Stack Overflow survey, about 45% of developers said they used it, making it the top front-end library.

How does your code prevent the form from being submitted? Why do we need to prevent it?

My code uses event.preventDefault() at the start of the submit event listener. Normally when you submit a form, the browser sends the data and goes to the page in the action, which for my form is formproccessing.html, so the page would reload or change. preventDefault() stops that from happening. We need it so my JavaScript can check the inputs first, like making sure there's a name, email, and shoot date, and show an alert if something's missing. Without it the page would just leave or reload, my checks wouldn't stop anything, and I wouldn't get to see my formData in the console.
