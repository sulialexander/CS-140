Suli's Selectors Engagement

  1. List out the different ways to select an item.
    - Tag name: p
    - ID: #idexample
    - Class: .classex
    - Descendant: main p selects every p anywhere inside main.
    - Child: main > p selects only the p tags directly inside main.
    - Others: grouping (h1, h2), universal (*), and pseudo-classes (a:hover).

  2. What is the difference between an ID and a Class?
    An ID is unique and is used once per page, whereas a class can be reused on several elements. An ID is used if you are only modifying one element, whereas classes are used if you want to repeat a particular style.

  3. What is the difference between a SPAN tag and a DIV tag?
    A span is used to style a small part of a paragraph or text without breaking the line. A div is a block element that wraps larger sections of content, and it starts on a new line and takes up the full width, so it creates a break before and after it.

  4. What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?
    A div says nothing about its content, while header, main, and footer are semantic tags that tell the browser, search engines, and screen readers what each section is. They look the same by default; the difference is their meaning and accessibility.

  5. What are the different ways to select a color?
    - Named: red
    - Hex: #ff0000
    - RGB: rgb(255, 0, 0)
    - RGBA: rgba(255, 0, 0, 0.5) adds transparency.
    - HSL: hsl(0, 100%, 50%)
