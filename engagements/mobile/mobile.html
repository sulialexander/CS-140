Questions

1. Why do we need a viewport meta tag?

To make sure the texts and images on a webpage look readable and normal because without it the webage won't automatically resize to the screen size its being viewed on but instead default to a width of 980px leading to all contents schrinking to fit the size, but it just looks awful.

2. If the same tag has "flex-direction: column;" in one rule and "flex-direction: row;" in another, which one takes priority?

The rule that comes later in the CSS file will be applied last

3. How do you change the CSS for a web page displayed on a phone?

You would use a media query which is a block in the css file that only applies when the screen size matches the size stated in the rule.

4. Pick a website you use on your phone. Name two things it changes on mobile compared to desktop.

On desktop, YouTube has a menu sidebar on the left but on my phone the side bar is on the bottom and all video widths fit my screen.

5. What width did you choose for your breakpoint, and why?

I chose 768px. When I dragged the page narrower in DevTools, the cards started getting too thin around that width. The text only fit two or three words per line, and the pictures turned into skinny strips. I picked the width where my content started to break, not the width of a specific phone, because there are too many phone sizes to design for each one.
