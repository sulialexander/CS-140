Form Styling Questions

  1. What are different ways to style your form?

    I grouped my fields using fieldset and legend, then used the box model (border, padding, margin, and border-radius) so each group looks like its own little box. I used flex to put each label right next to its field, and gave the labels a set width so all the fields line up nicely. I also added a :focus rule so whatever field you're typing in gets highlighted, and a media query that changes the layout on smaller screens so it still looks good on a phone.

  2. Why does the professor like to use flex?

    I used flex to line up my labels and fields side by side, and it only took a few lines of CSS. Gap made the spacing really easy, and switching to a stacked layout on phones only took one line: flex-direction: column. It was simple to set up and just as simple to change.

  3. What makes for a good mobile form?

    On a phone, I made the labels sit above the fields instead of beside them so the fields can use the full width of the screen. I also made sure the fields are big enough to tap with your thumb, and kept the text at least 16px so it's easy to read and the phone doesn't zoom in. I added a clear focus style too, so you can always see which field you're typing in.
