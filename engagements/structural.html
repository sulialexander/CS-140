Engagement - Structural Tags

Structural Tags (HEADER, NAV, MAIN, FOOTER).

- What goes in the header? Usually contain site logo, nav, and a searchbar.

- What goes in the Nav? links

- Can the Nav go in the header? Yes

- Does it have to go in the header? No, it can go before or after.

- Does the Nav contain links to another website? It can but it makes it more confusing to use

- What goes in Main? Main content that is diplayed in a webpage

- What goes in the Footer? Things like copyright

- HTML Validation: A website used to validate your HTML code. If theres any erros it will let you know what you need to fix
