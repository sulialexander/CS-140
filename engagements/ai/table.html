Questions

  1. Why don’t we use the border attribute?

    The border attribute isn’t really the best way to style tables because it doesn’t give you as much control as CSS does. With CSS, you can style things more exactly, and it’s easier to update and keep your code organized later on.

  2. What is the easiest way to color every other row a different color?

    The simplest way to give every other row a different color is to use the CSS pseudo-class :nth-child(even) or :nth-child(odd). That way you can style alternating rows without adding extra classes or inline styles to each one.

  3. What does the value in the parentheses of your pseudo-class mean? Give one other value you could use and which rows it would select.

    The value inside the parentheses of :nth-child tells it which position the element is in inside its parent. For example, :nth-child(2) picks the second child element. You could also use something like :nth-child(3n+1), which picks every third element starting with the first one (so the 1st, 4th, 7th, and so on).
